# Feature image options (exploration)

Prototype samples for four directions for article images:

- **A. Illustrated scene covers.** Vector motif kits per industry, brand-recoloured (`A-*.png`).
- **B. AI image plus our typography.** Brand frame only (`B-marine-frame.png`); the image slot is a placeholder because no image API was reachable when these were made.
- **C. Inline infographics from the article.** Comparison, steps and checklist renderers driven by JSON (`C-*.png`).
- **D. The client's own photo library with a brand treatment.** Described only.

Brand colours and names in the samples are placeholders, and the marine comparison values are illustrative.
Re-render with `node explorations/feature-images/render.mjs assets/fonts explorations/feature-images/samples`.
